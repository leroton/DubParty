# Разработка

## Требования

- Node.js и npm.
- Python 3.10+.
- Rust toolchain и системные требования Tauri 2 для запуска desktop-оболочки.

## Установка

```powershell
npm install
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r backend\requirements.txt
```

## Запуск в браузере для разработки

В первом терминале из корня проекта запустите backend:

```powershell
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8765
```

Во втором терминале:

```powershell
npm run dev
```

Откройте `http://127.0.0.1:1420`. Для теста на одном ПК откройте эту страницу ещё в отдельном профиле/окне и подключитесь к адресу интерфейса хоста. Backend должен быть запущен только один раз.

## Проекты и видеосцены

После входа в лобби хост нажимает «Создать проект» в общем чате, указывает название и выбирает видео. Создается отдельная проект-комната с вкладками «Просмотр», «Редактор» и «Чат»; вкладка озвучки появится позже. Launcher хранит проекты в `.dubparty-data\projects`; для другого каталога задайте `DUBPARTY_DATA_DIR` перед запуском. Если запускать backend отдельно, по умолчанию используется `%APPDATA%\DubParty\projects`. Поддерживаемые расширения: MP4, MOV, MKV, WebM, AVI и M4V. Воспроизведение зависит от кодеков WebView2/браузера; MP4 с H.264 и AAC имеет наиболее широкую поддержку.

Редактор поддерживает персонажей, цвета, текст и перекрывающиеся реплики. Таймкоды хранятся в миллисекундах. Сохранение выполняется автоматически после изменения, а также кнопкой «Сохранить». Общий чат и чаты проект-комнат имеют отдельные истории в памяти сервера. На этапе 2 проект редактируется только на компьютере хоста; остальным участникам передаются названия проект-комнат, но не исходное видео и разметка. Передача материалов появится на этапе 5.

## Запуск одним файлом

Запустите `run-dubparty.cmd` двойным щелчком или из CMD. Скрипт сам скачает portable Node.js и Python в `.runtime`, добавит portable Node.js в `PATH` для npm install-скриптов, установит npm- и Python-зависимости по `package-lock.json` и `backend\requirements.txt`, проверит наличие FFmpeg/FFprobe и при необходимости скачает Windows essentials build в `.runtime\ffmpeg`. Затем поднимутся backend и frontend. При запуске проверяются контрольные суммы файлов зависимостей; пакеты переустанавливаются при изменении или отсутствии. Нужен интернет; установка не требует прав администратора. Скрипт выведет адрес `http://127.0.0.1:1420`. Введите `status`, чтобы увидеть состояние сервисов, или `exit`, чтобы завершить только запущенные этим скриптом процессы. Если порты `8765` или `1420` уже заняты, скрипт сообщит об этом и не будет останавливать чужие процессы.

## Desktop

После установки Rust зависимости и Python-модулей запустите `npm run tauri dev`. Tauri запускает локальный backend при старте окна и завершает дочерний процесс при выходе. Backend запускается из `.venv`, если виртуальное окружение создано; иначе используется `python` из `PATH`. В разработке установите зависимости backend заранее; готовая установочная сборка и упаковка Python runtime относятся к этапу стабилизации.

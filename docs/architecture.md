# Архитектура DubParty

Приложение использует React + TypeScript + Vite в оболочке Tauri 2. React обращается к локальному FastAPI на `127.0.0.1:8765` для управления лобби, импорта и сохранения проектов. Управляющий API не выставлен в виртуальную сеть. WebSocket-сервер комнаты запускается отдельно и привязывается к выбранному IPv4 адресу и порту. Это позволяет участникам подключаться через Hamachi/Radmin.

Сервер лобби является источником истины для участников, списка проект-комнат и историй чатов. Участники получают случайный UUID сессии на сервере. Сервер выдаёт временный токен возобновления сессии, а токен роли хоста передаёт только локальному управляющему клиенту; при реконнекте сервер сохраняет UUID, выбранную комнату и закрывает старое соединение. История каждого чата хранится в памяти процесса (последние 300 сообщений). WebSocket-сообщения имеют типы `lobby.snapshot`, `participants.updated`, `chat.message`, `projects.updated`, `room.snapshot`, `error` и `heartbeat.pong`; от клиента принимаются `chat.send`, `project.create`, `room.enter` и `heartbeat.ping`. Только хост может создавать проект-комнаты.

Проекты и видеофайлы сохраняются на компьютере хоста раздельно от исходников: launcher использует `.dubparty-data\projects\<project-id>\`, desktop backend по умолчанию — `%APPDATA%\DubParty\projects\<project-id>\`. Переменная `DUBPARTY_DATA_DIR` задает каталог проектов напрямую. `project.json` содержит метаданные, персонажей и реплики с таймкодами в миллисекундах; исходное видео хранится отдельным файлом. Реплика дополнительно хранит номер дорожки `lane`: при перекрытиях редактор выбирает свободную дорожку, чтобы блоки не накладывались. API импортирует видео потоково, ограничивает размер 20 ГБ и отдает его с поддержкой HTTP Range для перемотки. Редактор доступен хосту. Список проект-комнат и история их чатов хранятся в памяти сервера; при подключении хост повторно публикует список из локальных JSON-проектов.

FFmpeg и FFprobe находятся через `DUBPARTY_FFMPEG_BIN`, локальный `.runtime\ffmpeg\bin` либо `PATH`. Launcher автоматически загружает Windows essentials build, когда оба инструмента не найдены. Локальный API запускает FFprobe/FFmpeg отдельными процессами без shell, извлекает первую звуковую дорожку в PCM WAV 48 кГц stereo, обновляет статус/прогресс и поддерживает отмену. `audio/prepared.wav` хранится отдельно от `project.json`; JSON содержит только относительную ссылку. Во время подготовки занята одна FFmpeg-задача на весь локальный backend.

Управляющий backend запускается Tauri-процессом и завершается при закрытии приложения. Для веб-разработки backend запускается отдельной командой. Python-процесс комнаты создаётся как фоновая задача Uvicorn внутри управляющего процесса; он останавливается при завершении лобби или backend.

Привязка к выбранному IP ограничивает доступ конкретным интерфейсом и подходит для Hamachi/Radmin. Если требуется подключение через другой интерфейс, выберите его адрес явно. Привязка к `0.0.0.0` удобнее для нескольких сетей, но увеличивает поверхность доступа, поэтому в MVP она не используется. Временный токен лишь возобновляет серверную сессию и назначает хоста; он не является аккаунтом или защитой комнаты. Трафик внутри VPN не шифруется приложением: подключаться могут другие участники виртуальной сети, а текст виден серверу.
